# Blinkit Clone 🛒

For Priview :- https://somya9977.github.io/blinkit-clone/


A responsive **Blinkit (Grocery Delivery App) UI clone** built using **HTML and CSS**.  
This project focuses on recreating the look and layout of the Blinkit website to practice frontend development skills.

## 🚀 Features
- Homepage UI similar to Blinkit
- Responsive layout
- Product cards and categories section
- Clean and modern design

## 🛠️ Technologies Used
- HTML5
- CSS3

## 📌 Purpose
This project was created for **learning and practice** of frontend fundamentals such as:
- Page layout
- Flexbox & Grid
- Responsive design
- UI cloning
